# 岗位存活性校验

台账里的岗位会悄悄关闭——校招大量是「招满即止」，没有截止日，页面直接下架或按钮变灰。
**投之前先确认这个岗还在**，别填完一整张表才发现投不了。

## 什么时候要查

| 情况 | 查不查 |
|---|---|
| 台账条目 **≤7 天** | 不用 |
| **7~14 天** | 要投的那几个查一下 |
| **>14 天** | **全部重查**，或干脆重跑一轮扫描 |
| 岗位标了「急招」「招满即止」 | 每次投前都查 |

台账头部写了扫描日期，**跑 `date` 算算过了多久**。

## 怎么判断还在线

打开 A 级直达链接，看这几个信号：

| 还在线 | 已关闭 |
|---|---|
| 能看到完整 JD（职责 + 要求） | 跳 404 / 跳回列表页 |
| 有可点的「投递」「立即申请」按钮 | 「该职位已下线」「当前职位无法投递」 |
| — | 页面只剩导航和页脚，正文空了 |
| — | 按钮存在但置灰 |

**光看页面能打开不算数**——很多站下架后仍返回 200，只是正文空了。**必须看到 JD 正文 + 可点的投递按钮。**

## 批量查

用 `Workflow` 开几个 agent，每个查一批链接，返回 `在线 / 已关闭 / 打不开`。
已关闭的用 `scripts/set-status.sh "<公司>" "<岗位>" 过期` 改状态，**不要删行**——
留着能防止下次重复挖同一个岗。

## 顺带

查存活时如果发现**岗位名或截止日和台账不一致**，以官方页面为准更新台账。
聚合站的岗位名和截止日都不可信（见 `troubleshooting.md` 里聚合站失真那条）。
