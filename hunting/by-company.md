# 公司驱动找岗（用户给名单 → 逐家挖岗 → 用户选 → 登录 → 填表）

**触发**：用户给一串公司名（「帮我看看字节、美团、小红书」）。
和 `README.md` 的关键词驱动模式互补：那个是「给方向，全网搜」；这个是「给名单，逐家挖」。

## 一句话流程

```
名单 → 查台账去重 → 每家一个 agent 并行进官网挖岗 → 合并写台账 → 交清单
     → 用户选 → 用户登录 → agent 按 platforms/<平台>.md 填 → 用户点提交 → 回写
```

**agent 动手的只有「挖岗」和「填表」两段。选、登录、提交都是用户的。**

## 第 0 步：先查台账，别重复挖

```bash
grep -c "<公司名>" job-leads.md
```

`job-leads.md` 里已经有的公司（截至 2026-08-29 有 38 家、105 条）**直接复用**，只对台账里没有的公司开 agent。
台账超过 14 天的条目要重验（「招满即止」的岗可能已关）——重验也走下面的流程，只是目标从「找岗」变成「核岗」。

## 第 1 步：每家公司一个 agent，做完整解析链

每个 agent 拿到**一家公司**，独立完成：

| 子步 | 做什么 | 产出 |
|---|---|---|
| 1a 找站 | 搜「<公司> 校招 官网」「<公司> 2027届 校园招聘」；识别平台（飞书招聘 / Moka / 北森 / 自建） | 官方校招站 URL + 平台类型 |
| 1b 找岗 | 站内搜 `Agent` `大模型` `LLM` `智能体` `算法` `解决方案` `AI应用`；SPA 抓不到列表就找官方 JSON API（见 README 2.5 节） | 岗位列表 |
| 1c 拿 JD | 每个岗进详情页，拿 A 级直达链接 + JD 原文 | 每岗一条记录 |
| 1d 标关键词 | JD 里有没有 LangGraph / LangChain / MCP / RAG / Function Calling / Harness / Agent | `kw` 数组 |

**硬规则同 README 第 3 节**：链接必须真实、届次必须引原文、不预筛、截止日只填 ISO 不填剩几天。
**平台类型必须填**——它决定填表时读哪份 `platforms/<平台>.md`。

## 第 2 步：合并、写台账、交清单

同 README 第 6 节。清单格式同 README 第 7 节（直达 JD 链接 + JD 原文一句 + 平台）。
**清单里每条要带平台名**，用户选完我就知道该读哪份平台档案。

## 第 3 步：用户选 → 登录 → 填表（交接点）

用户说「投这几个」之后：

1. 对每个岗，从 `job-leads.md` 取 `平台` 字段 → 读 `platforms/<平台>.md`（没有就按 README 回写规则新建）
2. 导航到投递页。**没登录态 → 停下叫用户登录**（验证码红线，见 README 第 7 节）
3. 用户登录后，走 `CLAUDE.md` 标准流程填表，停在提交前
4. 用户点提交
5. 回写：`job-leads.md` 状态改「已投」+ 其余回写清单

**一次只填一家**。填完一家、用户提交了、回写了，再开下一家。不要并行填多家——登录态、浏览器标签、用户注意力都是单线程的。

## 输出格式（每家一份）

```json
{
  "company": "…",
  "career_site": "官方校招站URL",
  "platform": "飞书招聘 | Moka | 北森 | 自建 | 未知",
  "batch_evidence": "引用原文证明2027届开放",
  "positions": [{
    "title": "官方准确岗位名",
    "url": "A级直达JD链接",
    "grade": "A|B|C",
    "city": "…",
    "deadline_iso": "2026-09-15 或 null",
    "kw": ["LangGraph","RAG"],
    "jd_excerpt": "Agent/RAG相关原文",
    "how_to_find": "B/C级必填：进站怎么搜"
  }],
  "dead_end": "没找到时说明原因"
}
```

## 目标画像在哪改

**`hunting/target.json`** —— 届别、目标岗位、JD 关键词、FDE 同义词、站内搜索词都在这。
默认是 AI Agent + FDE。**换方向改这个文件，不要改脚本和 prompt。** 不含隐私，可以随仓库公开。

## Claude Code 跑法

```
// 用默认画像（target.json 的内容已内置在脚本里）
Workflow({ scriptPath: "<绝对路径>/hunting/by-company.js", args: ["字节跳动","美团","小红书"] })

// 或显式传画像（读 target.json 后传入，字段会覆盖默认）
Workflow({ scriptPath: "...", args: { companies: ["字节跳动","美团"], target: <target.json 内容> } })
```

每家一个 agent，超过 12 家自动分批。

## Codex / 其他 agent 跑法

每家开一轮对话：贴 `prompt.txt` 全文 + 「你负责这一家：<公司名>。按 by-company.md 第 1 步做完整解析链，按输出格式返回 JSON」。
