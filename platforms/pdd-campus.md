**联动链（重要）**：
```

  └→ 留学期间是否有出境记录*（是/否）
       └→ 留学期间是否参加线下授课*（是/否）
            └→ 线下授课累计时长*（1-6个月 / 7-12个月 / 一年以上）

  └→ 是否专转本/专升本/自考本科/持有前置专科学历*（是/否）
```
这些字段**只在选中上一级后才出现**，且**保存会静默失败**——不报错，只是把新字段显示出来。点保存后务必确认区块已退出编辑态。

## 技术细节

- **两套 UI 库混用**：多数下拉是 **Ant Design**（`.ant-select-dropdown`），但 **学校名称/语言能力那几个是 `rocket-select`**（`[class*=rocket-select-dropdown]`）。查错容器会以为下拉没打开。
- **rocket-select 的选项 DOM 是重复的**，过滤掉 `class` 含 `content` 的节点再数索引。
- **学校名称搜索有强干扰项**：搜「哥伦比亚大学」返回 `洛斯安第斯哥伦比亚大学 / 不列颠哥伦比亚大学(UBC) / 英属哥伦比亚大学(UBC) / 哥伦比亚大学`，**精确项排最后**。必须键盘 Down 到底 + 校验 `active` class 再 Enter。
- **Ant Design 的是/否下拉，Enter 有时不生效**，改用截图定位点击。
- **保存/取消**在区块右上角，截图坐标约 x=1308 / x=1249，相距 60px。点错静默丢弃全部改动。
- **编辑态锁标签切换**：区块显示「取消/保存」时点其他标签无反应，先保存。
