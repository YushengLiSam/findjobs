# 度小满校园招聘（campus.duxiaoman.com）

```
职位列表  https://campus.duxiaoman.com/051736/position/list?current=1&limit=50   ← limit 可调，一页拉全
职位详情  https://campus.duxiaoman.com/051736/position/<postId>/detail
投递表单  https://campus.duxiaoman.com/051736/resume/<postId>/apply
```

前端同样是 **Formily（`ud-formily-item`）**，与得物同源，`platforms/dewu-campus.md` 的战术基本通用。
但**控件皮肤不同**（`ud__select__*`），下拉行为差别很大，见下。

## 硬性规则

- **同期最多 2 个投递在流程中**（表单顶部横幅会写「还可以投递 N 次」）
- **「投递顺序代表志愿顺序」**——页面明写。**最匹配的岗位要第一个投**
- 2027 届校招，岗位共 39 个，北京为主、少量上海

## 翻页无效，用 URL 参数

分页按钮点了不动（SPA）。直接 `?current=1&limit=50` 一页拉全，再用 JS 抽：
```js
[...document.querySelectorAll('a[href*="/position/"][href*="/detail"]')]
```

## ⚠️ 下拉：选项以低透明度渲染在下方字段之上

**截图上看下拉是空的，其实选项已经渲染了**——它们半透明地压在下面几个字段上面，
肉眼和截图都容易误判成「没打开」。**别信截图，用 JS 读 `[class*=ud__select__list__item]`。**

三种情况都遇到过：
1. 选项在视口内 → 取坐标用 `computer` 真实点击，可靠
2. 选项渲染在**视口外**（`top` 为负，如 -2135）→ 坐标点不到，**改用 JS 派发完整鼠标事件序列**：
   ```js
   ['pointerdown','mousedown','mouseup','click'].forEach(t =>
     it.dispatchEvent(new MouseEvent(t,{bubbles:true,cancelable:true,view:window})));
   ```
   这招在「获取校招信息渠道」和第二段教育的「学历」上都生效了。
3. **面板不销毁**：上一个下拉没关就点下一个，会点到残留面板。
   我因此把性别从「男」误点成「保密」。**每次选完先 Esc 或点空白关掉再动下一个。**

**读回显示值的选择器很难命中**（`select__selection__item` / `select__value` 经常返回空），
最可靠的校验还是**截图看**。别因为 JS 读回是空就以为没选上——我误判过两次。

## 日期控件：直接打字，别点面板

`点字段 → 输入 2025-09` 即生效。**打完不要再去点弹出的月份面板**——
我点了一次，结果年份被改成 2026（面板默认停在当前年）。输入后点空白 blur 即可。

## 文本框

React 原生 setter 有效（同得物）。但**子表单加了第二段后，同名 label 会有多个容器，
其中还夹着没有输入框的空壳**。定位第二段的正确写法是「取该 label 下**输入框为空**的那个容器」：

```js
const cs = items.filter(it => label(it)===kw).filter(it => [...it.querySelectorAll('input')].some(e=>e.type==='text'));
const target = cs.find(it => { const e=[...it.querySelectorAll('input')].find(x=>x.type==='text'); return e && !e.value; });
```

⚠️ **不要用 `scrollIntoView` 再算坐标**——它会让页面滚动，后续坐标全废。我因此把学历误改成硕士。

## 字段地图

| 区块 | 字段 | 备注 |
|---|---|---|
| 投递意向 | 推荐方式（默认无）、意向城市（只读） | |
| 上传简历 | 简历附件 | **不会自动解析**，其余字段仍要手填 |
| 个人信息 | 姓名 / 邮箱 / 年龄 / 性别 / 获取校招信息渠道 | 手机号平台自带 |
| 教育经历 | 起止时间 / 学历 / 学校名称 / 学院 / 专业 / **实验室 / 领域方向 / 导师** | 提示「请完整填写本科至当前最高学历」→ **硕士必须加两段** |
| 工作经历 | ☑ 没有工作经历 | 应届生勾这个 |
| 实习经历 | 公司名称 / 职位名称 / 起止时间 / 描述 | |
| 项目经历 | 项目名称 / 项目角色 / 起止时间 / 项目链接 / 描述 | |
| 作品 / 竞赛 / 证书 / 语言能力 / 社交账号 | 均为可选「添加」 | |
| 自我评价 | 单个 textarea | |

**「实验室 / 领域方向 / 导师」是度小满特有的**，多数平台没有——对有科研经历的候选人是加分位，别空着。

**学校名称是联想框**：输入后弹候选，注意同名陷阱（哥伦比亚大学 vs 哥伦比亚大学中心卡瓜斯分校；
威斯康星大学麦迪逊分校 vs 威斯康星大学学院/威斯康辛医学院）。**必须看清候选再点。**
