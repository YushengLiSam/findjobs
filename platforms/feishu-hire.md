# 飞书招聘（Feishu Hire）平台笔记

适用域名：`*.jobs.feishu.cn`

已验证：小鹏汽车校招、中际旭创全球校园招聘，2026-08-28。

## 页面结构

- 申请页是一个长页面 Formily 表单，教育、实习、项目等经历以动态重复子表单呈现。
- 多段经历会生成重复的 DOM ID；定位时必须先缩小到对应区块，再按 `data-form-field-name` 和段落顺序选择，不能全页缓存数组索引。
- 常见字段名：
  - 基本信息：`name`、`email`
  - 教育：`school`、学历下拉、`field_of_study`、起止年月
  - 实习：`company`、`title`、`desc`、起止年月
  - 项目：`name`、`role`、`link`、`desc`、起止年月
  - 语言：`language`、`proficiency`
  - 自我评价：`self_evaluation`
  - 社交账号：平台类型 + URL/ID

## 交互要点

- 学校字段是可搜索下拉：输入关键词后必须点击可见的精确选项，再读回控件显示值；只把文字写进 input 不算选中。
- 学历、语言、熟练度、社交平台等下拉都按可见文本精确选项操作，并在选择后读回确认。
- 年月字段可直接填写 `YYYY-MM`，填完读回。
- 页面未见分区保存或自动保存确认，只有底部最终提交按钮。不要刷新页面；填写完停在提交按钮前交给用户确认和提交。
- 简历上传若报 `fileChooser.setFiles failed: Not allowed`，需在 `chrome://extensions` → ChatGPT 浏览器扩展 → **Details** 中启用 **Allow access to file URLs**，然后回到原标签页重试。
- 公开职位详情可能显示“该职位已下线”，而已有申请链接仍可编辑。遇到这种不一致要明确报告，不要据此推断后台一定能或不能接收申请。
- 未登录打开 `/resume/<position_id>/apply` 会重定向到 `/login?redirect_path=...`。手机号登录页的国家区号可能默认 `+1`；中国大陆手机号要先精确选择“中国大陆 +86”，再填手机号。
- 登录前必须勾选“同意并阅读《隐私声明》”并获取短信验证码。隐私声明接受和验证码发送都需要用户参与；可以先填区号与手机号，但不要代替用户接受条款或擅自触发短信。
- 中际旭创官网 Q&A 明确：最多投递 2 个志愿，第一志愿流程终止后自动进入第二志愿；测评包含 AI 面试与线上笔试，且为必做环节。

## 安全边界

- 不点击最终提交。
- 上传前核对文件路径；提交前让用户逐项检查。
