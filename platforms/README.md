## 建档规矩

- 文件名：平台级用 `<平台slug>.md`，公司级用 `<公司slug>-campus.md`
- 文件头写清楚：`平台: 飞书招聘 | Moka | 北森 | 自建`、`域名:`、`最后验证:` 三行
- **建完回到本表加一行**，否则下个 agent 找不到
- 通用的浏览器坑写进 [`_ats-tactics.md`](_ats-tactics.md)，只在这个平台成立的才写进平台档案
