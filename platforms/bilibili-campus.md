# 哔哩哔哩校园招聘平台笔记

适用域名：`jobs.bilibili.com/campus`

已验证：2026-08-28，多模态Agent工程师【2027届】。

## 投递规则与流程

- 岗位页公开写明：2026-09 至 2027-08 毕业的学生可投，每人限投 2 个职位。
- 点击“投递简历”后会提示当前岗位自动成为第一志愿；“继续投递”只进入编辑页，不是最终提交。
- 未登录时点击“投递简历”会跳到 `passport.bilibili.com/login`；支持扫码、账号密码和短信登录。二维码有效期较短，若用户不能马上扫码，优先切到短信登录并先预填手机号，发送验证码前单独确认。
- 编辑页底部只有“取消 / 投递”。没有分区保存按钮；最终“投递”必须由用户本人点击。

## 页面字段

- 基本信息：姓名、性别、出生日期、所在城市、籍贯（可选）、手机区号与号码、邮箱；预计毕业时间由教育经历自动计算。
- 自由文本：`自我描述`，上限 1000 字。
- 动态区块：教育经历、实习/工作经历、项目经历、语言能力。
- 作品展示：作品链接、GitHub URL/ID、最多 5 个附件。
- 页面顶部另有“简历解析”上传入口；简历照片为独立上传入口。不要把三个 file input 混用。

## 交互要点

- 日期均为只读 Ant Design 年月选择器。点击月份框 → 点击 `.ant-calendar-month-panel-year-select` → 选择年份 → 选择月份。
- 勾选“至今”会移除结束月份 input，导致后续全页日期索引变化。必须在当前经历卡片内定位，或每次重新查询。
- 学历选择后会出现实验室、导师、研究方向等选填项。
- 语言能力：英语；档案中的“完全专业水平”映射为平台选项“无障碍沟通”。
- 简历上传使用可见的“选择文件”按钮触发 chooser；不要强制点击隐藏 input。若 `setFiles` 报 `Not allowed`，需在 Chrome 扩展详情中开启 **Allow access to file URLs**。
- 已手工填写字段后，顶部“简历解析”可能覆盖内容；需要仅附上原始简历时，优先用底部“附件”，上传后再逐项核对。
