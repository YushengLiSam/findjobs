# 北森招聘门户（Beisen / zhiye.com）平台笔记

适用域名：`*.zhiye.com`

已验证：摩尔线程校园招聘，2026-08-28；曙光 2027 校招，2026-08-29。

## 页面与地址

- 校招职位列表常见地址：`/campus/jobs`。
- 校招详情常见地址：`/campus/detail?jobAdId=<UUID>`。
- 直接打开申请表 `/form?fromPage=job&jobAdId=<UUID>`，未登录会重定向到 `/login?goto=form...`。
- 职位列表卡片可在当前页展开职责；详情页和申请页都以 `jobAdId` 作为岗位标识。

## 登录

- 摩尔线程站实际渲染的登录页为“微信扫码登录/注册”，并要求勾选“我已阅读并同意《北森隐私政策》”。条款确认和扫码登录必须由用户参与。
- 平台公开配置具备手机号验证码、邮箱、账号密码和扫码等能力，但具体租户页面未必全部展示；只按当前可见控件操作，不能假定隐藏方式可用。
- 应用内浏览器可能没有既有账号状态；不同 `zhiye.com` 租户是否共享资料也不能假定。登录后先逐字段核对旧存档。
- 未登录调用表单数据和门户投递设置接口会返回 `401 NO AUTH`，因此精确字段、必填项和联动只能登录后确认，不能拿通用北森表单冒充本租户 schema。

## 交互与读取

- 部分北森页面的可访问性快照可能为空，但页面已经完成渲染；这时可从当前页面 DOM 的可见 `body.innerText` 只读核对标题、岗位和登录提示。
- 申请表的字段、required 和租户自定义上传限制必须以登录后页面为准。
- 通用前端简历兜底规则：单文件、最大 50MB，支持 PDF/DOC/DOCX 等；租户可覆盖，上传前仍需以页面提示为准。
- 北森全页式申请表里的输入先只存在于当前页面状态；填写完不能只保留标签页。必须点底部“暂存”，重新打开后逐字段读回，再交给用户预览和提交。2026-08-29 摩尔线程实测：未暂存时重新加载，两条教育记录的学校和日期仍在，但 GPA、专业排名及部分学院字段回退或丢失。

## 投递限制与安全

- 摩尔线程公开接口未给出总投递数量上限；同一岗位不允许重复投递。
- 隐私政策、短信验证码、扫码、极验 CAPTCHA 均需用户参与。
- 上传个人简历前做行动时确认；已有文件不擅自替换。
- 不点击最终提交。

## 曙光 2027 校招（2026-08-29 实测）

- 已登录表单直接显示岗位名、校园招聘最多可投 3 个及当前剩余次数；`【2027】Agent FDE工程师-天津(J14199)` 当次显示还可投 3 个。
- 表单区块：个人信息、可重复教育经历、可重复工作经历、可重复获奖情况、简历附件；底部为「暂存 / 取消 / 预览并提交」。不点击「预览并提交」的最终提交步骤。
- 身份证号录入后，出生日期会由平台自动带出并显示；以页面读回值为准，不手工反推。
- 教育/工作起止时间是年月选择器（`YYYY-MM`），可按知识库月份精确填写；个人信息里的「毕业时间」是完整日期选择器且非必填，只有毕业年月时留空。
- 「现居住地」是可搜索的单选地区弹层。搜索广州后需先点结果左侧单选圆圈，使计数从 `0/1` 变为 `1/1`，再点「确定」；只点文字不会选中。
- 工作经历勾选「至今」后，结束时间输入框会禁用但仍显示「请选择」，这是正常状态。
- 页面通用提示：简历支持 PDF/DOC/DOCX 等，最大 50MB；仍需在行动时确认后才上传。
- 本岗位官网公开信息：曙光智算、天津、全职校招、2026-12-31 截止；同一岗位不可重复投递。


## vivo 校招（hr-campus.vivo.com，2026-09-05 实测）

⚠️ **域名**：校招是 `hr-campus.vivo.com`，社招是 `hr.vivo.com`，别搞混。

- **最多可投 1 个职位**，表单顶部显示「还可投递 N 个」。一次性，选岗要慎重。
- **简历解析可能只识别出 1 段工作经历**，而候选人实际有多段。
  ⚠️ **解析完必须数一遍段数，和 `experience_bank.md` 对得上再说**。
  加段落：点「添加工作经历」（ref 会失效，用 JS 派发 pointerdown/mousedown/mouseup/click 四连点）。
- **暂存后页面若再次重载，未暂存的改动会回退到解析器原始值**。改完立刻暂存，别攒着。
- 底部「预览并提交」旁边的暂存点完会出 `暂存成功，可在「投递记录」中查看` 绿色提示，
  **看到提示才算存上**。另外页面一旦被编辑过，导航会被 `Leave site?` 拦截 —— 这是常态，不代表没存上。
- **「暂存」不保存投递意向段**（面试站点、意向工作地点）——见 troubleshooting
  `2026-09-05-beisen-vivo-intent-not-saved`。提交前重选，选完别关标签页。
- **身份证号填完，出生日期自动带出**（和曙光一致）。
- **民族**是「点圆圈 → 看已选 1/1 → 点确定」的单选面板（和曙光的现居住地同款）。
- **英语证书名称下拉里有「未参加」**，选它之后**成绩栏自动消失**，不用编分数。
  搜索框直接输「未参加」能命中。
- **培养方式只有三个选项**：全日制统招 / 非全日制统招 / 交换生，**没有「海外及港澳台」**。
  海外学历只能选全日制统招（另两个明确是错的），记进推断清单。
- **成绩排名**选项：TOP1 / TOP5% / TOP10% / TOP20% / TOP30% / 其他。
- **工作性质**选项：全职 / 兼职 / 实习 / 其他。IBM 研究助理选「实习」。
- **掌握程度**（计算机能力）选项：普通 / 良好 / 精通 / 熟练。
- 日期字段**拒绝 React setter**，必须走面板：点字段 → 点 «/» 翻年 → **截图确认年份** → 点月份。
- 站内搜「Agent」共 39 条，校招 Agent 方向岗有 6 个：
  Agent技术工程师 / 同（知识管理方向）/ Agent开发工程师（数据方向）/
  软件工程师（Agent开发方向）/ Agent工程师（AI搜索方向）/ 前端开发工程师（Agent开发方向）。
- **面试站点标注了面试时间**（27届是 9月20-24日），10 个城市全现场，**无线上选项**。
  海外候选人投之前先看这个。
